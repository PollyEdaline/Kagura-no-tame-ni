# A Little List of Little Links

Hello, Kagura Games representative... and whoever stumbles across this while it's still public (shoo, shoo)! I wasn't sure of a better way to present my incredibly small public portfolio, so I'll just list them here for now.

### https://exhentai.org/uploader/liato
Contains a single comic from the artist *everyday2* that I edited and typeset. This was originally in Korean, and the provided translation was MTL, so unfortunately that's what I worked off of. There are some questionable choices here that I'd probably change now, but I decided to just post it and let it be.

### https://github.com/PollyEdaline/Starstorm-Text-Changes
Probably the easiest thing to show off without being on a Discord call, this is a bunch of editing I did for the Risk of Rain 1 mod, Starstorm. Mostly this was just small tweaks to language, but it also involved making every tooltip in the game follow a consistent set of rules, keywording, and formatting. I also did edit/rewrite some of the lore bits.

### https://github.com/one-pace/one-pace-public-subtitles / https://onepace.net/en
The main thing I work on now, and I've been working on it for about a year or so now. The brief spiel is that it's a fan project that re-edits the One Piece anime to more closely align with the manga, but we also do extensive editing on the subtitles starting from a (usually Crunchyroll) base. I do a LOT of work on this project as a subtitle editor and I'm more than happy to show off specifically what I've worked on - the public subtitle repo is sort of difficult to navigate, and you won't easily find what I've worked on unless you go to the latest stuff. I've worked on practically every episode we released in the last year.
